# Курсовая работа студентки Лисянской Алины, БКНАД241.
Личный кабинет разработчика тестов для платформы [motovskikh.ru](https://motovskikh.ru). Личный кабинет позволяет регистрироваться, подтверждать email и управлять своими тестами.
## Регистрация на сайте по ссылке: https://motovskikh.ru/hello/ (в более простой форме без паролей)

### Стек

**Backend:**
- Go 1.25.0
- MySQL + GORM
- JWT + cookies
- gorilla/mux
- go-swagger

**Frontend:**
- HTML + CSS + JavaScript
- Figma для удобной разработки дизайна

* Для генерации файлов устанавливаем [Свагер](https://github.com/go-swagger/go-swagger/releases)
